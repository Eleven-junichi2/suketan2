# requirements

## アプリ概要

1日のスケジュールのタスクの所要時間を記録し、24時間全体に対するタスクの時間管理かつ可視化をするアプリ。
具体的には、可処分時間の可視化などを目標にする。

## 機能

- 1日のスケジュールの記録・管理
- スケジュールにタスクを記録する
    - タスクの記録内容
        - 時間
        - 内容
        - グループ分けでの処理のためのタグ
    - タスクの時間の記録方法
        1. 開始時刻・終了時刻で記録
        2. 単に所要時間で記録  
        - 記録方法は後の可処分時間の計算に関わる
- 可処分時間の計算
    - 計算時、特定のタグのグループのタスクを除外して計算することができる。
